# Nivaãra Hotel Nerul

Standalone property website for **nivaara.ghdhotels.in**.

Boutique smart-comfort hotel in Nerul, North Goa — by GHD Hotels.

## Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Nodemailer (contact form SMTP)

## Run locally

```bash
cp .env.example .env.local   # if present — set SMTP_PASS
npm install
npm run dev
```

Open http://localhost:3000

## Deploy

Point **nivaara.ghdhotels.in** at this repository’s production build.
